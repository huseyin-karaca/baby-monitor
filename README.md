# Baby Monitor with Star Quality

A smart baby monitor that tracks a baby's temperature, movement, sleep and voice, built by the team StarSense
Ventures (Hasan Efe Akın, Ahmet Çobanoğlu, Tanel Gülerman, Hüseyin Karaca, Beyza Öge) for the METU Electrical and
Electronics Engineering capstone design course, 2023–24, advised by Ahmet Cemal Durgun.

**Project page:** <https://hkaraca.com/baby-monitor/> · **Video:** <https://youtu.be/aAMOuFkq0nw> ·
**Poster:** [PDF](docs/assets/poster.pdf)

The children's *mama*, *papa* and *dada* clips collected for the voice subsystem are released separately as
[MaPaDa](https://github.com/huseyin-karaca/mapada).

This repository holds the project page (`docs/`, `mkdocs.yml`, `overrides/`); build it with
`pip install "mkdocs-material>=9.5" "mkdocs<2" && mkdocs build --strict`. The poster and video are © 2024 the
StarSense Ventures team.
